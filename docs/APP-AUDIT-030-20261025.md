## Release assessment at the time of audit

**Resolve the P1 before integrating the release gate, and the listed P2 defects before publishing 0.3.0.** Prioritize:

- Existing APT feed renewal (REL01): the current gate rejects the published 0.2.5 policy. After integration this would block renewal and eventually allow the feed metadata to expire. This audit does not establish a current live outage. Preserve a hash-bound historical verification path.
- Memory bounds: wallpaper Fill preview (SET01) and project metadata reads (W01).
- Input and unintended writes: offscreen Notes keyboard ownership (RUN01), Arrange recovery/display targeting (RUN02–RUN04), onboarding destination/Apply handling (OB01, OB06), and stale scheduled switches (SET04).
- Recovery and updates: missing monitor geometry (TX01), stale Undo receipts (OB05, TX02), and enrollment/purge failures (U01–U03).
- Islands fallback, restart and placement correctness (IB01, IN01–IN03).

P1 denotes the release-gate integration blocker; P2 denotes a supported functional defect; P3 denotes lower-impact behavior. No P0 was confirmed in this review; this does not guarantee its absence. The two memory issues were checked under safe bounds; the multi-gigabyte allocation was not attempted.
