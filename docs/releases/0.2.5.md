# Halcyon 0.2.5

- More consistent light/dark colors, desktop restore and recovery from interrupted changes.
- Remember the chosen widget display, including disconnect and reconnect handling.
- Release desktop input when Arrange exits fail.
- Islands startup checks for COSMIC 1.10/1.11, improved update migration and stock-panel recovery. Islands controls appear when the add-on is installed.
- Four decorative glass finishes without requesting native backdrop blur.
- A usage-sharing checkbox in setup and App settings.

Install the main `.deb` for widgets and themes. Islands needs the separate matching `.deb`. `amd64` works on both 64-bit Intel and AMD PCs.

The focused COSMIC 1.11 software-rendered session test passed startup, input, child-process cleanup, stock recovery and relogin. Physical GPU and full COSMIC 1.10 coverage remain unverified; the reported RX 590 lockup is still under investigation. The updated release-family startup policy has focused local tests, not a separate native qualification run.

The collector upgrade is deferred. Opt-out works locally, but the current server rejects 0.2.5 activity and preference updates; queued preferences expire after seven days without re-enabling reporting. See [Privacy](../PRIVACY.md). Automatic APT-source enrollment is not yet available.
