# Halcyon 0.3.0

- **GPU rendering:** Settings and first-run setup now use the GPU renderer.
- **Settings:** reorganized navigation, desktop previews, Help and Recent changes.
- **Setups:** six starter configurations, including optional Islands layouts.
- **Widgets:** choose and order widgets during setup; assign individual widgets to displays.
- **Calendar:** read-only HTTPS/iCal subscriptions, calendar selection and Busy privacy mode.
- **Updates:** signed APT updates enabled by default for fresh installations. Existing disabled sources are preserved.
- **Fixes:** Islands switching and recovery, display layouts, calendar DST handling and activity reporting.
