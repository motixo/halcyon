# Halcyon 0.3.0

- Redesigned native Settings with six navigation categories and desktop previews.
- Six Setups with distinct layouts and optional Islands compositions. Review the included parts before applying.
- Per-widget display placement, disconnected-display choices and layout controls.
- Read-only HTTPS/iCal subscriptions, with calendar selection and Busy privacy mode. Google sign-in requires OAuth configuration and live acceptance remains pending.
- System updates enabled by default for fresh packages. Existing disabled or modified sources stay unchanged; the OS controls update installation.
- Help with local status and a report you can preview, copy or save.
- Recent changes showing manual edits, wallpaper colors and automatic switches. Undo remains limited to eligible changes.
- Keyboard focus stays visible when moving through scrolling settings.
- Upgraded activity reporting, including preference revisions, first desktop start when known, and current counts that exclude opted-out installations. The live collector passed activity and preference checks.

Islands and native bar finishes require the matching active companion. Finishes
are decorative; they do not add native backdrop blur or optical refraction.

The final main and Islands packages passed installation, native input, crash
recovery and relogin checks in a complete COSMIC 1.11 KVM session.
[Acceptance and remaining limits](./0.3.0-acceptance.md). Google sign-in, physical
hotplug/resume, screen-reader operation and longer hardware sessions remain
unqualified. The VM showed a stock-panel rendering artifact, recorded with the evidence.
The collector upgrade was deployed and live-tested on 2026-10-26. Historical
reports rejected before that upgrade are not reconstructed. See [Privacy](../PRIVACY.md).
