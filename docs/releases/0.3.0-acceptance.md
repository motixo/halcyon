## Scope and limitations

The base image SHA-256 is `4b26c9e9f3430a070d0c48d781f127837b3ce300c62384179aa5a9eeb51a1cc6`. Graphics were virtio/Mesa llvmpipe on one 1280×800 output; KVM accelerated the CPU. The guest had no network device. No host installation was replaced.

Initial standard-mode captures showed pixel speckles outside the dock. The same artifact appeared with the verified unmodified stock panel after recovery, and disappeared on a later stock login. It is recorded as a VM/stock rendering limitation; a driver-level cause was not established. Islands captures after toggling were clean.

Earlier CPU-emulated runs are not counted as successful Islands startup: Mesa crashed with emulated AVX2, and a reduced CPU model exceeded the unchanged readiness deadline and recovered to stock. The first network-backed staging harness timed out while its child later completed; the preserved follow-up verifies the selected generation. No product deadline, generation guard or failure gate was bypassed for the successful KVM acceptance.

Physical hotplug, mixed-DPI/resume, clean COSMIC 1.10, actual Flatpak applets, screen-reader operation and sustained GPU/battery behavior remain unqualified. Live Google Calendar OAuth is pending. The live reporting collector is separately upgraded and verified.

## Supporting validation

The application audit completed 1,125 passing Rust tests (11 existing ignored), including 67 new regressions; the vendored recurrence library passed 300 tests and Python suites passed 212. Final packaging/helper changes have additional focused tests. All 38 collector tests passed. The final main ELF passed compact, wide, 150% and light Settings checks; the final native ELF passed three toggle cycles with a second bar visible and a missing named output.

The release asset `halcyon-0.3.0-focused-native-evidence.zip` contains the raw observations, captures, harness code, package receipts and selected logs. Its inventory hashes every member. `companion/compatibility/evidence/accepted-final-030.json` binds this evidence and the final package/helper bytes. Historical 0.2.5 evidence was not reused to qualify these binaries.
