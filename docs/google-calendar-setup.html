HALCYON · CONNECTIONS

Your calendar, on your desktop.

In a configured release, open Settings → Widgets → Calendar, click Connect Google Calendar and approve access in your browser. Choose the calendars to display. You can switch accounts or disconnect from the same page.

Halcyon reads events and meeting links; it cannot create, change or delete events. Your Google password is entered only on Google's website. The app stores its connection in your system keyring and caches event titles, times, descriptions, locations and links in private local files.

If this build says sign-in is unavailable
The publisher must register a Google app before sharing the release. Ordinary users should not need to create a Google Cloud project. For your own personal build, you can perform the registration below yourself.

Calendar links (0.3.0 development)

Open Settings → Widgets → Calendar → Add calendar link. Give the calendar a name and paste its HTTPS or webcal subscription link. Add up to eight feeds, then select which ones appear. This connection is read-only and works without Google OAuth configuration.

For Google Calendar, use Settings → Settings for my calendars → Integrate calendar → Secret address in iCal format. Work or school administrators may disable this address. Google’s instructions.

The link is a credential: keep it private. Halcyon saves it in your system keyring and fetches the feed directly from its provider. No Halcyon server receives it. A subscription connection replaces the current Google connection on this computer; you can use several subscription calendars together, or several calendars from one Google account.

Recurring events, all-day events, exclusions and moved/cancelled occurrences are supported. Feeds must use UTC, local floating times or standard IANA time zones. Custom time-zone definitions, recurrence ranges such as THISANDFUTURE and oversized feeds report an error and keep the previous agenda. CalDAV, local .ics files and feeds requiring a separate username/password are not supported.

Using the agenda

Today and Tomorrow work in both the Calendar widget and compact At a glance. Click an event title for details; Join opens its meeting link. Earlier reveals finished events. Enable Hide event details to show Busy while keeping times visible. Existing events remain available when a refresh fails.

One-time publisher setup

  1. Open the Google Cloud console. Create or select a project owned by the publisher. Enable the Google Calendar API.
  2. Configure Google Auth Platform: app name, support contact, audience and consent information. Choose an audience that includes your intended users. An internal Workspace app is limited to its organization; an external app can support users outside it. During testing, add the intended accounts as test users.
  3. Request these scopes: openid, email, https://www.googleapis.com/auth/calendar.events.readonly and https://www.googleapis.com/auth/calendar.calendarlist.readonly. Follow Google's publishing and verification requirements for your audience and requested scopes before a public release.
  4. Create an OAuth client with application type Desktop app. Download its JSON file. A Web application or service-account JSON file will not work.
  5. For a local build, open Calendar settings, expand Advanced → Google sign-in setup… and select Import Google app JSON…. For a packaged release, pass --google-oauth-client /path/to/desktop-client.json to scripts/install.py. This installs the publisher configuration beside the app; users then get the Connect button.
  6. Test sign-in and reconnect with an ordinary user account. A Workspace administrator may restrict third-party apps even when Google's consent screen is configured correctly.

The desktop client configuration identifies the publisher; it is not a user's access token. The app uses a system-browser sign-in, a random localhost callback port, state validation and PKCE. It never uses an embedded login browser.

If connection fails

  • Browser did not open: choose Open sign-in page or Copy sign-in link, then use Firefox, Chrome, Edge, Zen or another normal browser on this computer. Finish before the five-minute timeout.
  • Keyring unavailable or locked: start or unlock a Secret Service-compatible keyring, such as GNOME Keyring or KWallet. Halcyon does not fall back to saving tokens in plain text.
  • Access denied: approve both Calendar permissions. For a test release, confirm the account is an allowed test user. For work accounts, ask the administrator whether this app is allowed.
  • Expired connection: select Reconnect. Offline updates keep the last saved agenda and show that it is saved data.
  • Disconnect: removes this app's saved connection and cached events on this computer. Your Google events remain unchanged. To remove the app's Google grant as well, use Google account connections.

Existing installations

An installation that already used the local Workspace integration keeps that connection during the upgrade. A fresh installation does not borrow another app's Google credentials. Disconnecting an existing Workspace connection removes Halcyon' access to it without modifying the other app's credentials.
