# Release screenshots

0.3.0 development captures and provenance: [0.3.0 native captures](030/README.md).
The files below are historical release evidence, retained under their original names.

The 0.2.0 material images are actual native captures of the release packages in
an isolated COSMIC session. They use the bundled Halcyon Night wallpaper,
ordinary native applets, synthetic checklist notes and real system readings.
No Calendar account or personal note is used.

- `materials-chooser.png`: a crop of the real 820×600 Appearance window.
- `materials-frosted.png`, `materials-clear.png`, `materials-smoked.png`,
  `materials-liquid.png`: the same desktop and wallpaper with each finish.

The chooser thumbnails are finish previews. The desktop images show actual
widget and companion rendering; they are not optical-refraction simulations or
hardware-performance comparisons. Colors and readability depend on the theme,
wallpaper and compositor. The transparent Clock intentionally stays transparent.

The existing kingfisher welcome image and older real-desktop gallery are retained.
Some older gallery images show an existing Google Calendar connection; check the
release notes for whether sign-in is configured in a particular package.
