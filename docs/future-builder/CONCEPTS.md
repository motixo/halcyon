# Concept map

All twelve images are in the [portable gallery](concepts/index.html). They are generated design targets, not current screenshots or exact specifications. The [manifest](concepts/manifest.json) records prompts, provenance and image hashes.

| Concept | Supporting work | First useful scope |
| --- | --- | --- |
| [Tidal](concepts/01-tidal.png) | Style, typography, no-surface components, placement | Sparse editorial preset |
| [Moss](concepts/02-moss.png) | Shared colour/type, rounded surfaces, stacked clock, music art | Coordinated soft preset |
| [Paper](concepts/03-paper.png) | Analogue face, light tokens, native Notes/Focus presentation | Quiet light preset |
| [Carbon](concepts/04-carbon.png) | Compact typography, meters, borderless parts | Dense technical preset |
| [Canvas](concepts/05-canvas.png) | Model resolution, measurement, layout, scoped drafts, transactions | Native object inspector with keyboard equivalents |
| [Widget builder](concepts/06-widget-builder.png) | Stable instances, recipes, bindings, bounded actions and rendering | Small trusted part vocabulary |
| [Community](concepts/07-community.png) | Portable packages, manifests, credits, fallback and revision identity | Local files first; curated hosted discovery later |
| [Ridge](concepts/08-ridge.png) | Structured wallpaper assets, fit transform, component rendering | Prepared foreground pair with validated fallback |
| [Spine](concepts/09-spine.png) | Vertical work area and native panel adaptation | Standard vertical panel; no vertical Islands promise |

| [Mix board](concepts/11-mix-board.png) | Selective-domain composition, provenance and common preview | Combine local picture, style and layout |
| [Type wall](concepts/12-type-wall.png) | Font catalogue, component previews, bounded cache and shaping | Installed fonts/styles shown on the user's picture |

## Other Fable ideas retained

| Idea | Disposition |
| --- | --- |
| Day line and Next up | Built-in timeline/agenda variants after the shared component path; later a recipe part |
| Fit to picture | Explicit layout suggestions only; image variance is not reliable subject recognition |
| Setup card | Real-rendered sample-data export before a hosted gallery |
| Now-playing tint | Optional artwork-derived colour, local to Music and event-driven |
| Grain and matte | No-surface/matte first; subtle bounded textures when the renderer and assets are ready |
| Focus/meeting Sessions | Deferred until activity override and restoration rules are designed |
| Timed live trial | Deferred pending crash-safe rollback and conflict design |

Every concept has a place in the project; not every concept is required for the first release. See [ROADMAP.md](ROADMAP.md) for dependencies rather than treating this table as a single implementation batch.
