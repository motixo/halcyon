# FB18 — portable setup packages

Setups can export a `.halcyon` file with credits and an optional shared wallpaper.
Import adds it to the local library for review; applying still uses the existing
domain selection, capability checks and Undo. Plain profile and sample-image exports
remain available.

The package carries declarative settings, an immutable revision and at most one
PNG picture. Export normalizes an explicitly selected PNG/JPEG and removes image
metadata. Accounts, notes, locations, physical display assignments, slideshows and
local paths are excluded. Built-in wallpapers retain their IDs. Included pictures
require an author and license; metadata does not grant trust or install Islands.

The envelope is limited to 24 MiB, its profile to 256 KiB, and its picture to 16 MiB,
16 megapixels and 8192 pixels per side. Image decoding runs in an owned child with
CPU, address-space and wall deadlines; cancellation reaps that child before releasing
its slot. Parsing rejects an oversized raw profile before constructing nested values.

Imported pictures are private immutable objects, published and synchronized before
the library entry. Plans and Apply verify their digest. An interrupted import can
leave an unreferenced object, but cannot publish a missing picture. The 64-object,
256 MiB pool preserves assets for history, drafts and recovery; it does not perform
automatic deletion. Profile format 14 retains package identity, parent and credits.

## Validation

Exact source, test results, native captures and artifact hashes are recorded in
[evidence](evidence/fb18-20261027.json). Sixteen new regressions cover bounds,
metadata stripping, source replacement, interrupted publication, retained assets,
independent source/destination roots, keyboard export, late import and worker cleanup.
307 distinct focused Rust checks pass, including the 16 new cases. Affected profile, store, native-job, image-worker, recipe, Clock/Weather and automation
suites also pass.

The final release ELF passed private COSMIC flows at 820×600 and 1280×800. Each
imports an independently generated envelope, verifies its retained picture and
credits, performs four Apply/keyboard Undo cycles, and opens export review. Captures
were inspected. All private children were reaped. File chooser saving is covered by
native-tree/file-IO tests; a live portal was not exercised.

Review corrections include explicit personal-picture restoration after portable
conversion, digest checks at Apply, durable retry after interrupted publication,
bounded child decoding, review-time source identity, and worker admission after
navigation. A recipe Clock typography regression found during review was also fixed.
The wide probe initially raced Undo removing a file; the observer now retries the
complete sample, with the failed run retained.

Physical cross-device transfer and installed-package qualification remain separate
acceptance items. No host configuration, installation, publication or version change.
