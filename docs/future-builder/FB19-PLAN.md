# FB19 implementation boundary

- Discover uses six real bundled Halcyon designs, with native previews, bounded
  search, author/license and capability-aware review. It works offline. Imported
  community packages enter the existing library; there is no invented remote feed.
- Curated IDs are stable across app updates; revisions bind the unfitted portable
  source, independent of local displays, content and installed capabilities.
- Remix opens a frozen picture/style/layout draft. Save creates a new library ID;
  source entries, applied desktop and scheduled references stay unchanged.
- Package origin retains up to sixteen unique source revisions and their credits.
  Export and Mix preserve the lineage; overflow fails rather than dropping credit.
  New lineage uses profile 15/package 2; old 14/package 1 remain readable.
- Source navigation resolves exact local revisions. A newer bundled revision is
  offered separately for review. No automatic refresh overwrites a personal copy.
- Native compact/wide navigation, offline search, personal-copy independence,
  source/update review, credits, format admission and Apply/Undo are acceptance gates.
