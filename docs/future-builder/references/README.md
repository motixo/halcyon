# References and provenance

The twelve generated concepts, their [manifest](../concepts/manifest.json) and [prompts](prompts.json) are copied into this project folder. Original task evidence remains untouched. No temporary-directory or account-specific path is required to view the gallery.

## Visual inspiration

- [end-4 dots](https://github.com/end-4/dots-hyprland): expressive typography, coordinated desktop modules and rich visual controls.
- [HyDE gallery](https://github.com/HyDE-Project/hyde-gallery): complete coordinated looks and broad style variety.
- [Caelestia shell](https://github.com/caelestia-dots/shell): integrated desktop presentation and consistent component design.
- [Noctalia](https://github.com/noctalia-dev/noctalia): modular shell customization reference.
- [Dux Shell](https://github.com/duxlabs-dev/dux-shell): compact overview and desktop modules.
- [COSMIC community example](https://www.reddit.com/r/unixporn/comments/1spxwwi/cosmic_on_pop_os_first_rice_with_limited_options/): native COSMIC customization context.

These are inspiration links from the earlier research, not dependencies or compatibility claims. Third-party screenshots, dotfiles and artwork are not copied into the redistributable concept folder. Shipping assets and fonts require their own provenance and licences.
