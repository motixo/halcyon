# FB15 — Day and Night Moments

Validated locally on 2026-10-27. [Evidence](evidence/fb15-20261027.json).

Moments adds two local widget styles, Day and Night. Each has a shared look and
optional Clock face, weight, italic and surface choices. Base settings remain
intact. Wallpaper, native bars, placement and app content stay outside this layer;
fonts, time format and size stay shared.

The Moments page previews either phase using fixed public samples. Selecting a
preview never activates it. Use Day/Night changes only the active selector.
Ordinary style choices save immediately to the named phase. The Clock inspector
defaults to the active phase and offers All moments for base edits. Inherit
removes the phase override. Canvas drafts retain their original phase through
scheduled switches, recovery and Apply.

Schedules use the existing automation engine. Rules containing Moments require
format 2; older setup-only rules retain format 1. Ordered rule priority resolves
coincident events. Resume, DST, clock rollback, latest missed event, manual
changes, rule revisions and Restore use the existing guarded policy. A schedule
switches once and does not continually reapply a look. Solar/activity triggers
and animated transitions remain outside this slice.

Portable profile format 12 carries explicit Moment choices; schedules stay local.
Profiles without Moments retain their previous minimum format. Existing store
transactions own Apply, conflict checks and Undo. A Clock action additionally
checks its rendered phase at commit time. No extra service or timer was added.

## Validation

- 189 distinct focused regressions passed, including 14 new cases. Two existing
  explicit probes remain ignored; no new test is ignored.
- Release build, changed-file formatting and whitespace checks passed. The final
  formatting step only sorted two module declarations; the evidence records the
  compiled and final text hashes separately.
- Native keyboard activation and public samples fit 820×600 and 1280×800.
- Private COSMIC release windows passed six activation/keyboard Undo cycles at
  both sizes, inactive-phase Clock editing and exact configuration restoration.
  Warm retained memory changed by 0.07/0.05 MiB in those bounded runs.
- The real desktop switched between Day analog and Night digital with unchanged
  geometry/wallpaper. Six switches restored the original config; a five-second
  static idle sample recorded zero commits/frame requests and zero sampled CPU.
- Review corrected partial-save defaults, commit-time phase races, preview city
  privacy, compact card clipping and outdated schedule-choice expectations.
  The native capture helper now waits for a fresh image; early stale captures
  remain preserved and are excluded from final visual acceptance.

The implementation stays on Config until FB16. These private sessions do not
qualify physical displays, long battery use, installed packages or screen readers.
No commit, installation, publication or application version change was made.
