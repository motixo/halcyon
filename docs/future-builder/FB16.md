# FB16 — canonical widget design

Implemented and locally validated, 2026-10-27. [Evidence](evidence/fb16-20261027.json)
records the exact source, binaries, tests and private native sessions.

The existing store now owns `design-v1.json`. Migration preserves all nine widget
identities, hidden state, ordering, local display placement, explicit and automatic
sizes, presentation and Moment layers. Config is a derived runtime/editor view;
the original widget fields are frozen migration evidence. Provider connections,
notes, location and other local preferences keep their existing owners.

Recovery offers an explicit review and **Migrate widgets** action. Settings,
controller writes, setup application, canvas edits, Restore and Undo use the same
journaled boundary. An interrupted activation is recovered before desktop startup.
Missing, newer or damaged designs never silently start a default desktop.

An older app changing the frozen fields pauses widget editing. **Keep current
design** first archives those changes and their history, then restores the frozen
source without replacing the applied design or unrelated local preferences.
Original-byte export works even for an unreadable schema. Legacy export is explicit
and refuses unrepresentable instances; it is a private downgrade file, not sharing.

The ID type distinguishes reserved legacy widgets from opaque instance IDs. Runtime
admission currently accepts the nine reserved instances only. Extra instances are
rejected rather than flattened; duplication remains unexposed.

  existing native-theme fixture remains ignored. 18 controller unit tests and nine real CLI transaction tests passed.
- Failure/interruption coverage includes activation, combined native/local/design
  writes, conditional recovery, old and new Undo, concurrent writers and source repair.
- The release binary and retained FB15 binary exercised old-client conflict detection,
  explicit legacy export, unknown-version rejection and exact original-byte export.
- Actual private COSMIC sessions passed at 820×600 and 1280×800, including six
  activation/Undo cycles. A migrated desktop switched between analog/digital Moments;
  its five-second idle sample recorded zero CPU ticks, surface commits or frame requests.
- Native migration/recovery captures were inspected. All private sessions were reaped.
  Protected wizard production files and the twelve original concept images are intact.
