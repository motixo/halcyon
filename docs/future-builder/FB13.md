# FB13 — sample images and Spine

Implemented, reviewed and locally validated on 2026-10-27.
[Evidence](evidence/fb13-20261027.json) records exact sources, artifacts and checks.

“Save preview…” saves a 1280×720 PNG through the local file chooser. It renders
the full selected setup with public sample content, separately from the domains
selected for Apply. Existing editable setup/theme export remains available.

The renderer starts with a validated portable record, default configuration and
a public reference canvas. It does not read the applied desktop, cached display
geometry, accounts, notes, music artwork or live providers. Only compiled bundled
pictures and colors/gradients are eligible; personal and unlisted pictures are
omitted and labelled. Clock and Weather use their shared native presentation;
other cards and applets remain explicitly illustrative. The time is fixed.

A short-lived headless native renderer uses the existing two-worker admission,
cancellation, child ownership and resource bounds. PNG encoding also uses that
admission. Selection, navigation and Cancel retire unfinished work. Completion
compares the current editor source and name, including observed library refreshes,
before opening a chooser. Rendering and saving never apply the setup. No hosting,
new dependency or new live provider was added.

Spine adds a standard vertical panel with an open Clock, Weather and system
readings. It appears in the setup studio without changing the first-run choices.
A vertical profile blocks enabled or unreadable Islands intent and guards the
observed setting through Apply. It keeps applets and display binding, and uses the
existing combined transaction and Undo. It never silently disables Islands.

passed before the final view corrections; all new cases, the complete Settings UX
module and native profile-image cases passed afterward. Compact/wide release

rendering, cancellation and confined atomic saving were checked separately.
Physical devices, screen readers, arbitrary native applet layouts, vertical
Islands and final packages remain qualification gates. No installation or release.
