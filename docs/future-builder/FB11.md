# FB11 — desktop canvas and native inspector

Implemented, reviewed and locally validated on 2026-10-27.
[Evidence](evidence/fb11-20261027.json) identifies the exact source and artifacts.

“Edit desktop…” in Layout opens a local canvas. Existing widgets can be selected,
moved and resized with the mouse or keyboard. The Clock inspector adds face,
surface, weight and font choices; shared widget typography remains explicitly
labelled. Inherit restores the existing style default or shared font. Readability
and missing-font fallbacks retain the saved choice. Existing content and account
editors remain separate.

Moves, sizes and styles stay in one draft. Apply uses one existing guarded store
transaction and one Undo receipt. Cancel discards the draft; Ctrl+Z inside the
canvas undoes local edits. Navigation and closing retain unfinished work in one
private recovery record. Outside changes to edited fields conflict; unrelated
content is preserved. Input received during a write cannot queue up and replay
as ordinary edits after Apply closes the canvas.

The wide inspector scrolls independently of the canvas. Compact controls use the
native page scroll area; Cancel and Apply remain fixed. Settings chrome follows
the native theme. A missing wallpaper uses a labelled neutral background that
keeps transparent clock text readable in light and dark Settings.

## Review and validation

controls were exercised at 820×600 and 1280×800, including mouse dragging,
keyboard movement, resize, inheritance and confirmation. Light/dark captures were
inspected. Release builds, formatting and whitespace checks pass.

Two actual private COSMIC release windows completed 26 Apply/Undo cycles each.
Their original fixture configuration was restored exactly; cancel wrote no
applied changes. RSS growth from cycle 5 to 25 was 0.79 MiB and 0.89 MiB. All
owned processes were reaped. Raw captures and intermediate review failures are
retained in `.task-future-builder-fb11-20261027/`.

The existing Config and placement model remain authoritative. General instances,
recipes, Moments and picture/style/layout composition retain their later stages.
Clock/Weather use shared native presentation; other existing card samples remain
illustrative. Missing-output recovery records are retained when their original
contexts cannot yet be admitted. Physical display transitions, screen readers,
capture-free timing/idle and exact package acceptance remain release gates.
No installation, publication or version change.
