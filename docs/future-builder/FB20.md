# FB20 — final local package acceptance

The implemented stages are assembled as a local development artifact:
`cosmic-ext-halcyon-dev_0.3.0~futurebuilder20261027.2_amd64.deb`.
It carries no release-update enrollment or maintainer hooks. The application remains
0.3.0; the working 0.5 target has not become a release. Nothing is published or
installed on the host.

## Local acceptance

[Evidence](evidence/fb20-20261027.json) identifies the final source, package and ELF,
retained test evidence and exact native workloads.

- Package payload hashes, permissions and resource delivery; the extracted executable
  matches the final reviewed ELF. Native probes use the packaged wallpapers.
- Actual dpkg install → upgrade → remove → purge in a private user namespace/root;
  personal files survive. Dependencies are intentionally unsatisfied in that tiny
  root (`--force-depends`), so this qualifies payload lifecycle, not a live OS install.
- Private source install/upgrade with system integration disabled, previous-binary
  backup and unchanged preferences. Review found and fixed a missing Ridge PNG in
  the source installer. Four source-install and five Debian-builder tests pass.
- Twenty-seven controller checks, including nine transactions against the extracted
  Rust executable; six retained-old/new CLI compatibility scenarios.
- Packaged native package-import/Apply/Undo, discovery/remix/Apply/Undo, prepared
  Ridge at 150% and canonical personal recipes. Owned child cleanup is checked.
- A source archive includes the new modules, assets and vendored recurrence fix;
  member digests and offline Cargo metadata verify its contents. It has no private
  task evidence, build directories or credentials.

## Release gate still open

FB20 remains in progress for a shipping release. Private compositor and filesystem
fixtures do not replace physical hotplug/resume/reboot, real mixed-DPI outputs,
hybrid/discrete GPU and longer battery tests, or screen-reader acceptance. A final
release-identity package still needs its reviewed companion pin and live COSMIC,
Store/PolicyKit installation acceptance. Live provider acceptance was not rerun here.

The local implementation and package checks are complete; these remaining checks
are recorded explicitly rather than counted as passes. Earlier scoped implementation
evidence stays frozen and is not regenerated from newer sources.
